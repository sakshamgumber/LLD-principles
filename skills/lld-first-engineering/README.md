# LLD-First Engineering Skill

This directory contains the **`lld-first-engineering`** skill package for AI agents and engineering workflows.

## Contents

- **[`SKILL.md`](SKILL.md)**: The core skill instructions and rule definitions loaded by AI coding assistants.
- **`references/`**: Comprehensive guides, checklists, and decision trees:
  - [`lld-review-checklist.md`](references/lld-review-checklist.md): 12-section review checklist for validating an LLD prior to requesting approval.
  - [`pattern-selection-guide.md`](references/pattern-selection-guide.md): 6-step framework to determine if a design pattern is warranted.
  - [`solid-principles.md`](references/solid-principles.md): Practical guide to applying SOLID without dogma.
  - [`general-design-principles.md`](references/general-design-principles.md): KISS, YAGNI, DRY, Encapsulation, Demeter, and Composition over Inheritance.
  - [`creational-patterns.md`](references/creational-patterns.md): Factory, Builder, Prototype, Singleton, and DI patterns.
  - [`structural-patterns.md`](references/structural-patterns.md): Adapter, Facade, Decorator, Proxy, Composite, Bridge, Flyweight.
  - [`behavioral-patterns.md`](references/behavioral-patterns.md): Strategy, State, Observer, Command, Chain of Responsibility, etc.

For full installation guides and workflow documentation, see the [root README](../../README.md).
